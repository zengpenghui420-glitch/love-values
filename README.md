# 恋爱观匹配度测试 · 你和TA到底合不合适

付费移动端 H5 娱乐测验。18 道原创 Likert 题，六维画像 + 恋爱观契合指数 + 六档锐评 + 适合的TA画像。

## 在线地址

https://zengpenghui420-glitch.github.io/love-values/

订单号在页面上做格式检查。格式通过就进入测验，不请求服务器，也不证明已经付款。页面上的「还可以测 N 次」按订单号记在这台浏览器的 `localStorage`（键 `love_values_order_uses`）。显示满 3 次之后，格式正确的订单号仍然可以进入，提示改为「验证成功」。已发出的访问码仍走原来的 vault，quiz 键是 `values`。

## 订单号

订单号没有后端计数。页面不为订单号请求 `*.vercel.app`，也不读写 Mantle 的 `orders/`。

| 项 | 值 |
|---|---|
| 格式 | 只接受 `P` + 18 位。重复块和逐位 ±1 的序列在页面上拒绝，19 位也不接受 |
| 通过 | 立刻解锁并开始，没有绑定、没有限流、没有服务器次数 |
| 显示 | 第一次开始记 1 次，提示「验证成功，还可以测 2 次」。重新测试再记 1 次 |
| 不记 | 刷新、继续这一次、查看上次结果、刷新结果都不改显示次数 |
| 记满之后 | 仍然可以进入，提示「验证成功」，不拦截 |
| 存放 | 只在本机 `localStorage`，按订单号分开记，键 `love_values_order_uses` |

## 已发出的访问码

仍走本页原来的 vault：`https://snappy-tundra-7uesdvk.tmp.now` 的 `POST /redeem`（代码里保留 `GET /get`）。剩余次数以 vault 返回为准。页面不另做旧码入口。本测验的访问码不接 Mantle。订单号不走 `/order/redeem`、`/order/get`。
